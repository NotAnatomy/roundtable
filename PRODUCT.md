# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Anatomy uses a local Mac app to talk to several AI collaborators together.
## Product Purpose
A shared conversation with independently configured agents, aware of each other's actual replies.
## Operating Context
Codex and Claude Code subscription logins already work on the user's Mac. Existing rooms and messages must be retained across updates.
## Capabilities and Constraints
One user message triggers at most one reply per selected agent, then all stop. Rooms choose one to four agents, with individual providers, model IDs, reasoning effort, roles, and instructions. Add Google Gemini API, AgentRouter API, and an official Antigravity subscription route if supported. Keep secrets local to the Mac, out of exports. Never simulate live responses or promise access to an unavailable model.
## Brand Commitments
Name: Roundtable. Familiar group chat inspired by Grok Bot and SillyTavern. Preserve readable, restrained dark styling and pink accents. The user dislikes em dashes.
## Product Principles
The human controls the pace. Shared context is explicit. Configuration reflects real capabilities. Errors are actionable. Existing conversations survive upgrades.
