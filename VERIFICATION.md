# Roundtable 0.10.0 verification

`npm test`: 66 passed, 0 failed. Tests make no paid model calls and no live GitHub calls.

Coverage includes:

- Real local HTTP server with fixture native CLIs: one reply per selected agent, later speakers see earlier replies, incremental resumed prompts, room switching during generation, interruption, persistence and retry in place.
- Codex thread and turn sandbox types, late item completion, reported usage.
- Claude CLI stream-image input and reported usage; Antigravity stream protocol and pinned effort handling.
- Bootstrap launch-secret gate, request authorization, Host/Origin protection and secret redaction.
- Gateway environment cleanup, workspace guards and resolved symlinks.
- Exact serialized transcript capacity, older attachment metadata and code-aware mentions.
- Image storage, content deduplication, invalid-file rejection and Google/AgentRouter image request formats.
- Actual client helpers for persistent drafts, room-switch attachment races, send completion preserving edited text and isolated delta updates.
- Actual safe Markdown DOM construction, including inert script text, rejected javascript links, no remote images and hidden reference definitions.
- Retention: completed replies lose their retry file, failed, interrupted and in-flight replies keep it, unreferenced uploads older than the grace period are swept, and deleting a room removes only the uploads no remaining room references.
- Archive and delete against the real server: archive clears native sessions and keeps messages, both actions are refused while the room is replying, delete requires the exact title, archived rooms refuse new messages, and deleting every room leaves a usable empty one.
- A shared notes edit between turns keeps the incremental native prompt instead of resending the transcript.
- Decoded media bytes per request are bounded independently of page count.
- Generated avatars are deterministic per agent ID, differ between agents, build only SVG namespace elements and contain no image or external reference.
- Routines: schedule validation including the 15 minute floor, local wall-clock next-run maths across a day boundary and a Friday-to-Monday weekday filter, due selection, every blocked-run reason, and the self-pause after three runs that could not start. On the real server a test run added the routine's message plus one reply from each participant, the message carried its routine label and the replies did not, and a room switched to allowing project edits refused the run.
- Secrets: reserved names covering every stripped provider variable plus the process-loading variables, the value length floor, duplicate names, and redaction including overlapping values and values below the floor. On the real server the value reached the agent's process environment, did not appear in its prompt, was redacted from its reply, and was absent from the state sent to the browser and from `rooms.json`; the name and description did reach the prompt; deleting the secret removed it from the room and from its file.
- Agent characters: silhouette geometry closes and stays inside the 32px box for every shape, markup is deterministic per agent at a fixed gradient id and differs between agents, no element references anything external, and the lifecycle mapping covers idle, thinking, working, streaming, done, failed and sleeping.
- Command palette ranking (prefix over word start over subsequence, hint hits below title hits, stable order on ties) and find-in-conversation ranges (non-overlapping, case-insensitive, empty and null inputs).
- Unread counts (open room excluded, never negative after a reset, unopened rooms start read, damaged storage ignored) and background-room completion detection.
- Reset on the real server: clears messages, pins and sessions, keeps title, agents and notes, refuses a second reset on an empty room, refuses while a room is replying, and removes only the attachments no other room references.
- Task list: tracker nesting, plan updates that keep children across a label change, bounds, Claude and Codex label mapping, the DOM renderer's in-place diffing and derived counts, and protocol fixtures on the real server (Codex commandExecution item and Claude TodoWrite plus Read/tool_result) persisting tasks with the message.
- Voice with a mocked fetcher: dictation request shape and transcript extraction, key redaction, PCM to WAV framing, Markdown stripping for speech, the browser WAV encoder's header and sample scaling.
- Skill import with a mocked fetcher: raw SKILL.md, repository listing without body fetches, folder scoping, depth and result caps, rejected hosts, credentials, redirects, oversized responses, rate limit responses, and the instructions-only limitation carried into the saved skill and the agent prompt.

- Browser rules: scheme allowlist, Roundtable's own origin refused, local and private addresses refused outside a Work room, the action allowlist with every rejected shape, ref bounds, page-report trimming with its truncation note and ref cap, login validation, and origin matching that refuses a look-alike domain, plain http, a different subdomain and an opaque origin.
- A real installed Chromium browser, driven headless: a page read with numbered elements, text typed through the real input pipeline and read back, a password typed by Roundtable that is absent from the page text and reported as `(filled)`, a submit that navigates and reports the page that arrived, history, a JPEG screenshot, and a stale ref from an earlier page refused rather than clicked. Skipped when no browser is installed, or with `ROUNDTABLE_TEST_BROWSER=0`.
- The browser as an agent reaches it, on the real server: with browsing off the command is not on the agent's path and the prompt never mentions it; with browsing on the prompt carries the command list, the saved sign-in names and the untrusted-page rule but neither username nor password; the per-turn token is handed to the process, works during the turn and is refused after it; the window's own token is refused on that route; and the guards answer before a browser would be launched. Sign-in values are absent from the bootstrap state and the file holding them is mode 0600.

Additional local check: PDF.js extracted known text and rasterized a real one-page PDF containing text and graphics. The check used the runtime's installed canvas library, not an application dependency. It caught missing modern-engine functionality; the bundled PDF.js legacy compatibility build resolved it.
