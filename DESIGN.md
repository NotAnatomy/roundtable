# Roundtable interface
Mode: Operate. Extend the existing dark group chat for a Mac user who also uses the app on smaller screens.
Use a quiet charcoal canvas, subdued pink controls, and provider color only for participant identity. System UI typography, 14px conversation text at a 76 character measure, with secondary controls at 11 to 13px. Room navigation at left, conversation in the center, a collapsible roster and shared notes at right. Creation and editing use one focused dialog with progressive disclosure for project context. Connections have a separate dialog and never mix credentials with room exports. No decorative images or invented sample conversations. Stop and connection errors stay visible. Use native dialogs, buttons, labels, and select elements. On mobile, navigation and roster become drawers. The composer stays reachable; code blocks scroll within messages.

The conversation renders semantic Markdown. User text has a subdued filled surface; agent replies are open editorial text with provider identity, compact actions and readable inline code. The composer plus menu adds text/code, skills, participants or notes. No fake reactions, monitors, routines, or capability badges. The right rail carries agent skills, notes, pins and the turn contract. A saved key is never labeled connected without a test result.
