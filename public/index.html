Skills

Build a small toolkit for the way you work.

These are reusable instructions. Assign them in each agent's settings. They do not install tools, scripts or external connections.

Any public GitHub repository using the Agent Skills format works. Roundtable reads SKILL.md instructions only; scripts, references and assets are never installed.

Routines

A message you wrote, sent to a room on a schedule.

A routine sends its message and the room takes one normal turn: one reply from each selected participant, then it stops. It cannot start another turn by itself. Each run spends the same provider quota as a message you send. A room that allows project edits cannot carry a routine, because nobody is there to approve a change.

Secrets

Values your agents' commands can use, that your agents never see.

A secret is an environment variable given to Codex, Claude or Antigravity when they run in a room you assigned it to. Their commands can read it. The value is never put in a prompt, never written into the conversation, and removed from a reply if a command prints it. The name and your description are shown to the agent so it knows what it may use. API participants run no commands and are never given secrets.

Values are stored in a private file in your Roundtable data folder, readable only by your user account, with user-only permissions. This is a plain local file, not the macOS Keychain, and it is excluded from exports. A secret is not a website login: Roundtable has no browser and cannot open or fill web pages.

New secret

8 to 4,096 characters. Once saved it is never shown again; enter a new value to replace it.
